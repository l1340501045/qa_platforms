# 优惠券批量发放平台 PRD（UI/UX 小批次验收样例）

## 1. 背景

运营同学需要把不同面额的优惠券批量发给目标用户，用于拉新、召回和活动补偿。当前人工发放效率低，且失败后难以定位原因。优惠券批量发放平台用于上传用户名单、配置发放规则、提交发放任务、查看异步结果并导出失败明细。

本 PRD 用于 QA 平台 UI/UX 小规模真实跑批验收，不作为生产需求。

## 2. 角色与权限

| 角色 | 权限 |
|---|---|
| 运营专员 | 创建草稿、上传名单、提交本人创建的发放任务、查看本人任务、导出本人任务结果 |
| 运营组长 | 拥有运营专员权限；可查看本组所有任务；可重试本组失败任务 |
| 管理员 | 查看全部任务；可停止任意进行中的任务；可导出全部任务结果 |
| 访客 | 只能查看任务列表，不允许创建、提交、停止、重试或导出 |

权限规则：

1. 访客点击“新建发放任务”时，按钮置灰并提示“无创建权限”。
2. 运营专员访问他人任务详情时，页面提示“无权查看该任务”。
3. 管理员停止进行中任务时，必须二次确认；确认后任务进入“已停止”。

## 3. 新建发放任务

### 3.1 字段

| 字段 | 类型 | 必填 | 规则 |
|---|---|---|---|
| 任务名称 | 文本 | 是 | 2-30 个字符；不可全为空格；同一创建人当天不可重复 |
| 优惠券模板 | 下拉单选 | 是 | 只展示状态为“启用”的模板 |
| 发放原因 | 下拉单选 | 是 | 可选：拉新、召回、活动补偿、客服补偿 |
| 发放时间 | 单选 | 是 | 可选：立即发放、定时发放 |
| 定时发放时间 | 日期时间 | 条件必填 | 当发放时间为“定时发放”时必填，且必须晚于当前时间 10 分钟 |
| 备注 | 文本 | 否 | 最多 200 个字符 |

### 3.2 保存草稿

1. 必填字段缺失时，不允许保存草稿，并在字段下方显示错误原因。
2. 草稿不校验用户名单文件。
3. 草稿状态下可以继续编辑字段和重新上传名单。

### 3.3 提交任务

1. 提交前必须已上传用户名单。
2. 提交时系统校验名单文件；校验通过后创建异步发放任务。
3. 提交成功后跳转任务详情页，并展示状态“排队中”。
4. 任务提交后，任务名称、优惠券模板、发放原因、发放时间不可再编辑。

## 4. 上传用户名单

### 4.1 文件格式

只支持 `.csv` 文件，文件大小不超过 10MB。

CSV 必须包含以下表头：

| 表头 | 必填 | 说明 |
|---|---|---|
| user_id | 是 | 用户 ID，必须为正整数 |
| coupon_count | 是 | 发放张数，必须为 1-5 的整数 |
| phone | 否 | 手机号，若填写必须为 11 位数字 |

### 4.2 文件校验

1. 缺少 `user_id` 或 `coupon_count` 表头时，上传失败，提示“名单缺少必填表头”。
2. 文件超过 10MB 时，上传失败，提示“文件大小不能超过 10MB”。
3. 单个文件最多 5000 行数据；超过 5000 行时，上传失败，提示“单次最多导入 5000 行”。
4. `coupon_count` 小于 1 或大于 5 时，该行标记为失败，不阻断其他合法行。
5. `phone` 不为 11 位数字时，该行标记为警告，不阻断提交。

### 4.3 上传结果

上传完成后展示：

- 总行数
- 有效行数
- 失败行数
- 警告行数
- “下载失败明细”按钮

当失败行数大于 0 时，允许提交有效行；失败行不会进入发放任务。

## 5. 任务状态与处理

### 5.1 状态机

任务状态包括：

1. 草稿
2. 排队中
3. 发放中
4. 部分成功
5. 全部成功
6. 全部失败
7. 已停止

状态流转：

```text
草稿 -> 排队中 -> 发放中 -> 全部成功
草稿 -> 排队中 -> 发放中 -> 部分成功
草稿 -> 排队中 -> 发放中 -> 全部失败
排队中 -> 已停止
发放中 -> 已停止
全部失败 -> 排队中
部分成功 -> 排队中
```

### 5.2 任务详情

任务详情页展示：

- 任务名称
- 创建人
- 当前状态
- 发放原因
- 优惠券模板
- 总用户数
- 成功数
- 失败数
- 最近更新时间

当状态为“发放中”时，每 10 秒刷新一次进度。

### 5.3 重试

1. 只有“部分成功”和“全部失败”的任务允许重试。
2. 重试只处理失败用户，不重复处理已成功用户。
3. 重试前必须二次确认，文案为“仅重试失败用户，不会重复发放已成功用户”。
4. 重试成功后状态回到“排队中”。

### 5.4 停止

1. 只有“排队中”和“发放中”的任务允许停止。
2. 已停止任务不可再次提交、重试或编辑。
3. 停止后未发放用户计入失败数，失败原因显示“任务被人工停止”。

## 6. 任务列表与筛选

任务列表默认按最近更新时间倒序展示。

筛选项：

- 任务状态
- 创建人
- 发放原因
- 创建时间范围

分页规则：

1. 默认每页 20 条。
2. 可选每页 20、50、100 条。
3. 切换筛选条件后回到第 1 页。

## 7. 导出

### 7.1 导出范围

支持导出：

- 当前筛选结果
- 单个任务结果
- 单个任务失败明细

### 7.2 导出字段

导出文件格式为 `.xlsx`，字段包括：

| 字段 | 说明 |
|---|---|
| task_name | 任务名称 |
| user_id | 用户 ID |
| coupon_count | 发放张数 |
| status | 发放结果：成功、失败、跳过 |
| fail_reason | 失败原因；成功时为空 |
| updated_at | 最近更新时间 |

### 7.3 导出规则

1. 只有管理员、运营组长和任务创建人可以导出任务结果。
2. 访客点击导出时提示“无导出权限”。
3. 导出超过 100000 行时，系统创建异步导出任务；完成后在导出中心下载。
4. 导出中心保留最近 7 天的导出文件。

## 8. 错误提示

| 场景 | 提示 |
|---|---|
| 网络异常 | 网络异常，请稍后重试 |
| 模板已停用 | 优惠券模板已停用，请重新选择 |
| 名单全部无效 | 名单中没有可发放用户 |
| 重复提交 | 任务已提交，请勿重复操作 |
| 权限不足 | 无操作权限 |

## 9. 验收重点

QA 应重点验证：

1. 访客、运营专员、运营组长、管理员的权限差异。
2. 任务名称边界：1 个字符、2 个字符、30 个字符、31 个字符、全空格、当天重复。
3. CSV 表头缺失、文件超过 10MB、超过 5000 行、`coupon_count` 越界、手机号格式错误。
4. 草稿、排队中、发放中、部分成功、全部成功、全部失败、已停止之间的状态流转。
5. 部分成功和全部失败任务只重试失败用户。
6. 停止任务后二次确认、状态和失败原因。
7. 任务列表筛选、排序和分页。
8. 导出权限、导出字段、异步导出和 7 天保留期。
