## 1. 变更概述

**变更动机**：当前平台存在严重系统缺陷——用例生成后无处查看。侧边栏仅有"系统管理"和"导出中心"两个入口，无用例相关独立页面；批次工作台是死胡同（无面包屑、无返回）；导出需手填 UUID。需要重构信息架构，建设完整的用例查看、通知和可观测性体验。

**交付分段**：
- **第一段**：信息架构 + 树形用例库（批次快照过渡）+ 详情面板 + 通知 + 面包屑 + 可观测性 + 搜索 + 导出优化
- **第二段**：版本历史/差异对比视图（依赖后端逻辑用例 ID + 版本记录 API 就绪）

## 4. 新增功能详细说明

### 4.1 树形用例库（关联 US-07）

**A. 界面与交互说明**

- **布局**：左侧树形导航（PRD 文档 → 功能模块 → 用例标题），右侧用例列表/详情面板
- **树形层级来源**：
  - 第一层：PRD 文档（种子文档，即触发生成批次的文档）
  - 第二层：功能模块（复用 parse 阶段聚合结果，来自 provenance.source_section）
  - 第三层：用例标题
- **交互规则**：
  - 点击第一层/第二层节点：右侧展示该节点下所有用例的列表视图
  - 点击第三层（用例标题）：右侧展开用例详情面板
  - 树节点旁展示该节点下的用例计数
  - 支持展开/收起全部

**B. 筛选与排序**

- 按优先级筛选（P0/P1/P2/P3）
- 按 Review 状态筛选（待审/已确认/需修改/已删除）
- 按可信度筛选（高/中/低）
- 按批次筛选（最新/指定批次）

**C. 树根归属规则**

- 树根按"种子文档"分组（即触发生成的文档）
- 当用例 derived_from 引用了多篇文档时，该用例归属于种子文档树下，但 provenance 中标注其他引用来源

**D. 异常与边界状态**

- 系统下无任何批次时：展示空状态"暂无用例，请先在知识库中选择文档生成"
- 某功能模块下无用例（全部已删除）时：节点变灰但不隐藏
- 树节点超过 200 个时：支持虚拟滚动

### 4.2 用例详情面板（关联 US-08）

**A. 界面与交互说明**

- **布局**：右侧滑出面板（Drawer）或内嵌面板，宽度占页面 50%-60%
- **展示字段**（全部来自现有 API 返回，无需新建字段）：

| 区域 | 字段 | 来源 |
| :--- | :--- | :--- |
| 标题栏 | 标题、优先级 Tag、Review 状态 Tag | title, priority, review_status |
| 可信度 | 档位标签（高/中/低）+ 说明 | trust_level（修正后语义）, confidence_note |
| 前置条件 | 条件列表 | preconditions |
| 测试步骤 | 编号 + 操作 + 输入数据 + 每步预期结果 | steps[].step_number, action, input_data, expected_result |
| 预期结果 | 总体预期结果 | expected_results |
| 测试维度 | 维度标签 | dimensions |
| 溯源 | 来源章节 + 派生来源 | provenance.source_section, derived_from |
| 操作栏 | 确认/需修改/删除 按钮 | — |

**B. trust_level 语义修正**

- 当前后端返回整数 1–5（信源信任度，数字越小越可信），前端误按 0–1 百分比展示导致恒显示 100%
- 修正为档位展示：1–2=高可信（绿色）、3–4=中可信（黄色）、5=低可信（红色）
- 详情面板展示格式：「信源等级：{档位标签}」，若 confidence_note 非空则附加显示
- 禁止用百分比展示 trust_level

**C. 版本历史区域（第二段）**

- 展示该用例的版本时间线：v1 → v2 → v3...
- 每个版本节点显示：版本号、变更原因、变更类型（AI 重生成/人工编辑/需求变更）、操作者
- 点击版本可查看该版本快照内容
- 相邻版本支持差异对比（diff 高亮）

**D. 异常与边界状态**

- 用例数据不完整（缺少某字段）时：该区域显示"暂无"而非报错
- steps 超过 20 步时：折叠显示，点击展开全部

### 4.3 通知铃铛 + 站内消息（关联 US-09）

**A. 界面与交互说明**

- **铃铛位置**：Header 右上角，始终可见
- **未读指示**：有未读消息时铃铛旁显示红色数字 Badge
- **下拉面板**：点击铃铛展开消息列表（最近 10 条），底部"查看全部"跳转 /notifications
- **消息条目**：图标 + 标题 + 时间 + 点击跳转

**B. 消息类型**

| 类型 | 标题模板 | 点击跳转 |
| :--- | :--- | :--- |
| 生成完成 | "「{文档名}」用例生成完成，共 {N} 条" | /batches/:id |
| 生成失败 | "「{文档名}」生成失败：{失败阶段}" | /batches/:id |
| 质量门暂停 | "「{文档名}」需要澄清 {N} 个问题" | /batches/:id |

**C. 消息状态**

- 未读/已读：点击消息或跳转后标记已读
- 全部已读：通知中心提供"全部标记已读"按钮
- 预留字段：actor（操作者，默认"system"，多人协作时为具体用户）

**D. 异常与边界状态**

- 无消息时：下拉面板展示"暂无通知"
- 消息超过 100 条时：通知中心分页展示，不支持无限滚动

### 4.4 流水线可观测性（关联 US-10, US-13）

**A. 界面与交互说明**

- **位置**：批次工作台（/batches/:id）的阶段进度条区域增强
- **当前问题**：Steps 组件仅展示名称，不展示真实状态/耗时/失败原因
- **增强内容**：
  - 每个 stage 节点下方显示耗时（如"12.3s"）
  - 运行中的 stage 显示旋转动画
  - 完成的 stage 显示绿色勾号
  - 失败的 stage 显示红色叉号 + hover 展示失败原因

**B. 数据来源**

- 消费现有 `stage_artifacts` 表数据（已有 status/duration_ms/open_questions/started_at/completed_at）
- 通过 GET /api/v1/batches/:id 已返回的 stage_progress 结构

**C. 失败重试**

- 失败 stage 节点旁展示"重试"按钮
- 点击后调用 POST /api/v1/batches/:id/retry（从失败步开始）
- 重试后状态恢复为 running，继续轮询

**D. 与通知联动**

- 生成完成/失败均推送通知消息
- 失败通知包含卡在哪一步和失败原因摘要

**E. 异常与边界状态**

- stage_artifacts 数据缺失时（旧批次）：stage 显示为"wait"状态，不展示耗时
- 多次重试同一步骤时：展示最新一次的状态和耗时

### 4.5 面包屑导航（关联 US-05 强化）

**A. 所有子页面面包屑路径**

| 页面 | 面包屑路径 |
| :--- | :--- |
| 系统知识库 | 系统列表 / {系统名} / 知识库 |
| 系统用例库 | 系统列表 / {系统名} / 用例库 |
| 系统批次列表 | 系统列表 / {系统名} / 批次历史 |
| 文档详情 | 系统列表 / {系统名} / 知识库 / {文档标题} |
| 用例工作台 | 系统列表 / {系统名} / 批次历史 / {批次标题} |
| 全局用例中心 | 用例中心 |
| 通知中心 | 通知中心 |

**B. 交互规则**

- 面包屑每段可点击跳转
- 当前页名称不可点击（灰色文字）
- 面包屑位于页面内容区顶部（main 区域内）

### 4.6 全局搜索（关联 US-11）

**A. 界面与交互说明**

- **入口**：全局用例中心（/cases）页面顶部搜索栏
- **搜索维度**：关键词（用例标题+步骤内容）、系统筛选、优先级、Review 状态
- **结果展示**：用例卡片列表，点击跳转到所属系统的用例详情面板

**B. 搜索能力要求**

- 支持中文关键词模糊匹配
- 搜索结果按相关度排序（最匹配的排前面）
- 支持精确关键词匹配和模糊近似匹配
- 搜索延迟不超过 3 秒（500 条以内结果集）

**C. 异常与边界状态**

- 无搜索结果时：展示"未找到匹配用例，请调整搜索条件"
- 搜索结果超过 500 条时：分页展示，每页 20 条
- 搜索耗时超过 3 秒时：展示加载提示

### 4.7 导出体验优化（关联原 US-04 强化）

**A. 变更内容**

- 新建导出弹窗中：Batch ID / System ID 改为下拉选择器（支持搜索）
  - 批次选择器：展示"文档标题 - 生成时间 - 状态"
  - 系统选择器：展示"系统名称"
- 用例工作台（/batches/:id）增加"导出本批次"快捷按钮
  - 点击后直接创建该批次的导出任务，无需再填表单
  - 按钮仅在批次状态为 completed / archived 时可用

**B. 异常与边界状态**

- 下拉加载批次列表失败时：展示"加载失败，请重试"并支持手动输入 ID
- 系统下无批次时：批次选择器展示"暂无可导出的批次"

## 7. 非功能需求补充

- **用例树加载性能**：系统下 500 条用例时，树形首次加载完成时间不超过 2 秒
- **通知实时性**：消息从后端生成到铃铛 Badge 更新延迟不超过 5 秒（基于轮询）
- **通知轮询频率**：每 10 秒轮询一次未读消息数
- **搜索响应**：全局搜索结果在 3 秒内返回
- **多人预留**：通知消息和版本记录均预留 actor/author 字段

## 8. 约束与依赖

- 依赖 platform-api 提供：批次列表 API、通知消息 API、搜索 API、重试 API
- trust_level 语义定义须前后端同步修正
- 第二段版本历史视图依赖后端逻辑用例 ID 和版本记录 API 就绪
- 每条用例须有稳定逻辑 ID + 结构化步骤，为后续 Playwright 自动化动线预留锚点
