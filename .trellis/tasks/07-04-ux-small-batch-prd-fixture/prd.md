# 小规模真实跑批验收 PRD 样例

## 目标

准备一份可控的小型 PRD 样例，供 `feat/qa-platform-ux-modernization` 合 main 前跑真实小批次验收。

这份样例要足够小，避免像完整漫剧 PRD 一样跑几个小时；同时又要覆盖真实 QA 平台主链路所关心的规则类型：字段校验、权限、批量导入、异步任务状态、失败处理、导出。

## 需求

- 新增一份可直接上传到平台的 Markdown PRD。
- PRD 必须是独立业务场景，不依赖现有漫剧业务上下文。
- PRD 内容控制在 1-3 个业务模块，适合真实 LLM 小批次验收。
- PRD 应包含明确可测规则，避免只有介绍性文字。
- PRD 应能诱导生成器产出：
  - 正常主路径用例。
  - 字段边界 / 非法输入用例。
  - 权限用例。
  - 异步状态流转用例。
  - 失败与重试用例。
  - 导出用例。
- 需要更新 UI/UX 父任务的合并准备清单，指向该样例文件。

## 不做

- 不改平台代码。
- 不改后端生成逻辑。
- 不跑真实 LLM 批次。
- 不把样例当作生产需求文档。

## 验收标准

- `docs/acceptance/ux-small-batch-prd.md` 存在。
- 文档能作为平台上传资料使用，标题、模块、规则、状态、边界清晰。
- `main-merge-readiness.md` 明确推荐用该样例跑小规模真实批次。
- 有自审说明，解释样例为什么足以覆盖 UI/UX 主链路验收，也说明它不能替代完整大 PRD 质量回归。
