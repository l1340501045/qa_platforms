# UI 验收入口说明自审

## 结论

新增 `docs/acceptance/README.md` 是必要的小收口。此前样例 PRD、runbook、回填模板和合并清单分散在不同目录，周一执行时容易漏步骤或用错文档。入口页把这些材料串成一个执行顺序，能降低真实验收的操作摩擦。

## 价值

- 执行者不用先理解 Trellis 目录结构。
- 明确默认上传 `docs/acceptance/ux-small-batch-prd.md`。
- 明确跑完后要生成 `.audit/<batch_id>/` 并回填给 Codex。
- 明确 GO / NO-GO 仍以 main 合并准备清单为准。

## 局限

- README 不是验收结果，只是入口页。
- 它不能替代真实 LLM 批次、首次上手演练或新批次 `.audit` 审查。
- 它没有解决图片链路验收；如需验证视觉模型，仍要另补含图片的小 PRD。

## 是否偏离目标

没有。用户目标要求 UI/UX 重构对齐 QA 日常动线并可被真实探索验证。入口页本身不是产品 UI，但它让下一步真实验证更可执行，属于达成最终目标的准备工作。
