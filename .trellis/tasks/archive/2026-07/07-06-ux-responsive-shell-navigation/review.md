# 全局布局窄屏导航可用性 Review

## 改动摘要

- 桌面宽度继续显示固定左侧栏，菜单项、顺序和高亮规则不变。
- 窄屏宽度隐藏固定左侧栏，顶部显示 `MenuOutlined` 按钮。
- 点击菜单按钮打开 Ant Design `Drawer`，抽屉内复用同一套导航项。
- 抽屉菜单点击后会导航并关闭抽屉。
- Header 标题区加入 `flex: 1`、省略策略和通知区 `flexShrink: 0`，降低窄屏重叠风险。
- Content 窄屏 padding 从 24 收敛到 12，给主工作区更多空间。

## 批判性自审

### 是否偏离父任务

没有偏离。这个任务改善的是 QA 平台全局入口在窄屏/分屏下的可达性，不改变页面业务逻辑，也不改变生成主流程。

### 是否有重大产品决策被偷改

没有。首页 `/` 仍按现有规范跳转 `/review`；导航顺序仍是工作台、项目/系统、用例资产、全局搜索、导出中心；没有新增底部导航或第二套信息架构。

### 是否影响桌面体验

桌面仍渲染 `Sider`，宽度、菜单项和高亮判断保持原逻辑。变化仅是菜单点击函数被统一封装。

### 风险与限制

- 本机 API 和前端服务启动前没有完整业务数据，所以无法完成真实数据页面截图验收。
- 当前项目没有 Playwright 依赖，本次没有临时安装依赖；浏览器视觉验收留给服务启动后的人工/后续自动化检查。
- Ant Design `Grid.useBreakpoint()` 首次渲染前默认按桌面处理，避免桌面首屏闪成移动导航；真实小屏挂载后会切到抽屉导航。
