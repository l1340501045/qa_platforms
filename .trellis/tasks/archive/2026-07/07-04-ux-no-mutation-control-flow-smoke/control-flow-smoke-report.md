# UI 无副作用控件动线巡检报告

## 结论

本轮在不上传、不生成、不创建导出、不删除、不确认、不落库的前提下，验证了 QA 主动线中的关键控件：

- 知识库上传前的文档类型选择。
- 全局搜索结果到批次/来源文档的追溯入口。
- 批次工作台和用例资产的树控件。
- 导出中心新建导出弹窗的范围与格式选择。

结果支持一个有限结论：**当前 UI 的关键控件已经能支撑首次使用平台的 QA 理解“下一步入口在哪里”，可以继续进入真实小批次验收。**

## 操作边界

本轮只做无副作用操作：

- 没有上传文件。
- 没有点击“生成用例”。
- 没有创建批次。
- 没有确认、需修改、删除、触发迭代或落库归档。
- 没有点击导出弹窗的“创建”。
- 没有触发 LLM 网关。

## 风险与剩余验证

- 这仍然不是完整验收。上传类型只验证了 UI 选择和文案，没有实际上传文件验证 DB 中 `doc_type=prd`。
- 搜索追溯验证的是旧批次数据，不证明新批次质量。
- 导出弹窗只验证了入口和文案，没有创建导出任务。
- 批次树和资产树验证的是旧数据可浏览，不证明新跑批的模块树一定正确。
