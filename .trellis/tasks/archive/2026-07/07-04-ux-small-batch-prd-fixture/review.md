# 小规模验收 PRD 样例自审

## 结论

这份样例适合作为 UI/UX 分支合 main 前的小规模真实跑批资料。它比完整漫剧 PRD 小很多，但覆盖了真实 QA 平台主链路需要观察的规则类型：权限、字段边界、文件上传、异步状态、失败处理、重试、停止、筛选分页和导出。

## 为什么不是随便写个玩具 PRD

- 有明确角色权限，能验证生成器是否产出 access control 用例。
- 有字段长度、唯一性、条件必填、时间边界，能验证 boundary / invalid input。
- 有 CSV 文件格式和行级失败，能验证批量导入与部分成功。
- 有任务状态机，能验证 state transition。
- 有导出权限和异步导出，能连接 UI 平台的导出中心验收。

## 局限

- 没有图片，不能验证视觉模型链路；如需验证 `LLM_VISION_MODEL`，仍要另补含图片的小 PRD。
- 业务规模小，不能替代完整漫剧 PRD 的大规模模块树和生成质量回归。
- 样例不是生产需求，不应用于评价真实业务覆盖率。

## 对 UI/UX 目标的贡献

它让周一的小批次验收从“临时裁一个 PRD”变成“固定输入、可复验、可比较”。如果这个样例都无法从上传走到生成、审查、资产、搜索和导出，那就是 UI/UX 主链路或环境存在明确阻塞；如果它能跑通，再进入完整大 PRD 质量回归会更稳。
