# 知识库上传结果下一步动线 Review

## 改动摘要

- 上传结果弹窗中，成功上传的文档保留资料类型标签。
- 每个成功上传文档新增 `查看详情` 和 `生成用例`。
- `生成用例` 复用原有 `triggerGeneration(documentId)`，仍先弹确认框，成功后进入批次工作台。
- `查看详情` 跳转当前系统上下文下的文档详情页。
- 跳过、失败、图片资产统计保留在原弹窗中。

## 批判性自审

### 是否偏离父任务

没有偏离。父任务要求平台第一次上手也能理解主流程，本改动只补“上传完成后下一步去哪儿”的断点，不重做页面、不改变后端、不触碰 testcase generator。

### 是否影响主流程

不影响。列表里的原有 `生成用例` 行为被抽成同一个确认函数，调用的仍是既有 `triggerGeneration`；上传、解析、worker、批次生成配置都未修改。

### 可能风险

- 弹窗内 `生成用例` 会在上传结果弹窗上再打开确认框，属于可接受的二次确认交互；它保护真实生成任务不会被误触发。
- 当前仓库没有 React 页面级测试框架，本次没有新增脆弱 UI 测试，采用 lint、build、现有 UI 模型测试验证。
