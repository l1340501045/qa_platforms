# 阶段 C：用例资产树与共享浏览器 PRD

## 目标

把工作台和用例库中重复的用例树/表格逻辑收敛为共享的用例资产浏览模型和组件，并支持“模块 -> 多级分支树 -> 用例”的真实层级。

## 前置依赖

- 阶段 A 已完成或用户明确放行。
- 阶段 B 已完成，树控件的默认折叠/滚动问题已先修。

## 必做

- 新增共享树模型函数，将 `CaseTreeDocument` 的 `branch_path` 归一化为递归树。
- 选中任意节点时，右侧展示该节点及子树下所有用例。
- 工作台和用例库复用同一套模型函数、标签映射和可信度展示。
- 工作台审核操作、详情抽屉、自动跳下一条必须保留。
- 用例库稳定主集/全部资产/待分类视图必须保留。

## 不做

- 不改生成核心逻辑。
- 不强行要求用例步骤数变多。
- 不做整体视觉大改。

## 验收

- 类似 `账户授权 -> 账户选择弹窗（批创页） -> 分页规则` 的路径能显示为递归树，而非一个平铺长节点。
- `CaseTreeReview` 与 `CaseLibrary` 不再各自维护一套几乎相同的树构建逻辑。
- 审核确认/需修改/删除仍可用。
