# 阶段 D：信息架构与视觉重构 PRD

## 目标

在阶段 B/C 稳定后，重构平台整体信息架构、页面骨架和视觉层级，让具备 QA 背景、但首次使用本平台的人能按工作流自然完成任务，而不是在“系统管理/审核中心/用例库”等割裂入口之间猜下一步。

## 前置依赖

- 阶段 A 已完成。
- 阶段 B 已完成。
- 阶段 C 已完成或明确决定先跳过共享浏览器重构。

## 必做

- 导航从对象管理导向转为 QA 工作流导向。
- 首页/工作台能看到待处理事项、运行中批次、待澄清、待审核。
- 页面头、筛选条、统计摘要、状态标签、空态/错误态视觉统一。
- 保持现有路由兼容，避免深链接失效。
- 视觉风格适合企业内部 QA 工具：清晰、克制、可扫描，不做营销式 landing page。

## 不做

- 不引入重型 UI 框架。
- 不做登录/权限系统。
- 不重写后端生成逻辑。

## 验收

- 首次使用本平台的 QA 可按“系统/项目 -> 知识库 -> 生成/审查 -> 用例资产 -> 导出”理解页面。
- 关键页面在桌面和窄屏无明显遮挡/溢出。
- 主流程入口仍可达，状态和下一步操作清晰。
